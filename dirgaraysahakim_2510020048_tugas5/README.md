# Tugas 5 — Kartu Produk Toko D-Store

Mata Kuliah: Pemrograman Web 1  
Materi: Pertemuan 5 — CSS Box Model, Display & Position

## File proyek
- `index.html` — halaman katalog toko dengan empat kartu produk.
- `style.css` — seluruh CSS eksternal dengan komentar per bagian.

## Penerapan ketentuan
- 4 kartu produk, masing-masing memiliki gambar, nama, harga, dan tombol Beli.
- Box model: `padding`, `margin`, `border`, `max-width`, dan `box-sizing: border-box`.
- Badge `position: absolute` di dalam kartu `position: relative`.
- Navbar `position: fixed` dan kompensasi `padding-top` pada body.
- Judul kategori `position: sticky`.
- Gambar memakai `overflow: hidden` dan `border-radius`.
- Efek hover dan `transition` pada kartu, gambar, serta tombol.
- Kartu disusun menggunakan `display: inline-block` sesuai materi sebelum Flexbox/Grid.

## Cara menjalankan
Buka `index.html` dengan browser. Koneksi internet diperlukan untuk memuat gambar dari Picsum Photos.

## Catatan
Ini merupakan katalog demonstrasi front-end. Tombol Beli membuka aplikasi email dan belum terhubung ke sistem transaksi/backend. Gambar produk merupakan placeholder.
